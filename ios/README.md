# Unified AI — iOS

تطبيق SwiftUI لمستخدم واحد، يتصل بالنواة الموجودة في مجلد المشروع الرئيسي.

## البناء على Mac
1. ثبّت Xcode وXcodeGen (`brew install xcodegen`).
2. افتح Terminal في مجلد `ios` وشغّل `xcodegen generate`.
3. افتح `UnifiedAI.xcodeproj` في Xcode.
4. في Signing & Capabilities اختر فريق Apple Developer الخاص بك، وغيّر Bundle Identifier إلى قيمة فريدة تملكها.
5. اختر جهاز iPhone الخاص بك، ثم Build & Run.
6. شغّل خادم FastAPI على جهازك الشخصي خلف HTTPS آمن، وأدخل عنوانه ومفتاح API في شاشة الإعدادات.

## القيود
- لا توجد مفاتيح مضمنة في التطبيق. يتم حفظ المفتاح في Keychain على الجهاز فقط.
- يتطلب التطبيق HTTPS؛ لا يستخدم استثناءات ATS عامة.
- لا يمكن للآيفون الوصول إلى `127.0.0.1` الخاص بالكمبيوتر. استخدم عنوان HTTPS خاصًا يصل إليه الهاتف، مثل بوابة VPN/Tailscale HTTPS مضبوطة بشكل صحيح.
- Face ID أو رمز الجهاز يحمي فتح الواجهة، وليس بديلاً عن مصادقة الخادم.
- التطبيق واجهة عميل؛ تشغيل Ollama/Langflow يتم على جهاز أو خادم آخر.
- لم يتم اختبار البناء فعليًا على Xcode في هذه البيئة.
- TestFlight توزيع اختياري؛ يمكنك التثبيت على جهازك من Xcode باستخدام فريق المطور.
- يجب اختبار الخادم، شهادات TLS، وإعادة الاتصال على جهاز حقيقي قبل الاستخدام.
