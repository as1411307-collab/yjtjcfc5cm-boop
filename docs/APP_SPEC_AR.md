## عقود الاتصال

| العملية | المعاملات والنتيجة |
| --- | --- |
| `GET /sessions/{id}/messages/page` | `before_id=0` يفتح أحدث صفحة. يسترجع `before_id=<next_before_id>` ما يسبقها. تظل القراءة الأمامية متاحة عبر `after_id`. |
| `POST /chat` | الطلب يحمل المحادثة والرسالة والمزوّد. يستخدم عميل الهاتف معرّفاً ثابتاً لاستعادة الطلب. يرفض الخادم إعادة استخدام المعرّف نفسه مع محتوى أو إعداد سياق مختلف. |
| `GET /learning/events` | يقبل `after_id` و`limit` و`category` اختيارياً. يعيد بيانات وصفية. تتاح الفئات الست حتى حين لا توجد أحداث من نوع معيّن. |
| `GET /learning/export` | يستعمل المرشّحات نفسها. تضمين النص يمر عبر `include_content=true`. تعود مؤشرات الصفحة في ترويستي `X-Next-After-ID` و`X-Has-More` من اللقطة نفسها. |
| حدود الحجم | حد الخادم 200 حدث للطلب و5,000,000 بايت لتدفّق JSONL قبل الضغط. يبدأ الهاتف بـ50 حدثاً ويخفض حجم الصفحة تلقائياً إذا أعاد الخادم HTTP 413. |
| توليد Ollama | الحد الافتراضي 1,024 رمزاً للرد الواحد، وقيمة `OLLAMA_MAX_TOKENS` بين 1 و8,192. يسري أيضاً حدّ الوقت وحجم الجواب. |

## فحص أرشيف على Mac

يحتوي الملف `manifest.json` على الفئة وعدد الأحداث وآخر معرّف وبصمة SHA-256 لبايتات `events.jsonl` كما صدرت. يعمل أمر التحقق محلياً باستخدام Python 3 من جذر مستودع التطبيق.

```sh
python3 scripts/verify_learning_export.py ~/Downloads/learning.zip
```

يعرض الفاحص عدد الأحداث والمؤشر ونتيجة مطابقة البصمة. يفحص ترتيب الأحداث وتوافق الفئة وعدد السجلات واستبعاد حقول النص عند اختيار البيانات الوصفية. تعطي الأرشيفات السابقة التي تفتقد البصمة نتيجة صريحة بذلك. المطابقة الداخلية تكشف عدم الاتساق، وإثبات هوية ناشر مستقل يحتاج إلى توقيع موثوق خارج الأرشيف.

## نتائج تجربة التشغيل وحدودها

- مع Ollama 0.40.16، اجتاز كل من `smollm2:135m` و`qwen2.5:1.5b` توليد رد على طلب عبر HTTP وحفظه وإعادة الطلب ثم إعادة التشغيل والاستعادة من نسخة مشفرة. جُرّبت الإعادة بعد إيقاف اتصال النواة بالمزوّد. استغرقت تجربة Qwen الواحدة 4.62 ثانية للرد الأول. هذه عيّنة تشغيل واحدة.
- الردّان الصغيران لم يقدّما تفسيراً عربياً مناسباً لسؤال سبب زرقة السماء. تقيّم خانة نجاح التشغيل وصول الرد واسترجاعه. تحتاج جودة الإجابات واللهجة إلى تقييم مستقل على أمثلة ممثلة للاستخدام.
- على قاعدة اختبارية حجمها 67,182,592 بايت، اكتملت الاستعادة. بلغت ذروة الذاكرة التي قاسها Python عبر tracemalloc نحو 2.02 MiB في كل من الإنشاء والاستعادة. يشمل القياس تخصيصات Python فقط.
- برنامج الهاتف يستهدف iOS 17 فأحدث. يلزم لإثبات تجربة الجهاز توقيع البناء وتثبيته، وتجربة Face ID وإذن الميكروفون والمقاطعات والقفل والمشاركة إلى Mac، واتصال الهاتف بالخادم الخاص.
- يتطلب اختبار Langflow الحي تدفّقاً مهيّأ وعنوانه. الموافقات الموجودة تضبط إجراءات التطبيق الحالية. توقيع الموافقة بواسطة Secure Enclave والتحقق منه على الخادم متطلب مستقل لم يُنفّذ في هذه النسخة.
